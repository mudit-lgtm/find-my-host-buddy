
# Migration + SEO/AEO/GEO overhaul for sitehostfinder.online

## 1. Domain migration (site-host-finder.vercel.app → sitehostfinder.online)

Replace every reference in:
- `src/lib/seo/keywordMap.ts` → `BASE_URL = "https://sitehostfinder.online"` (single source of truth; sitemap + prerender + SeoHead all consume this).
- `index.html` → canonical, og:url, og:image, twitter:image, hreflang, all JSON-LD `url`/`@id`/`item`/SearchAction target.
- `src/pages/Results.tsx` → canonical rewrite target.
- `src/lib/seo/toolContent.json` → any embedded absolute URLs.
- `public/sitemap.xml` (regenerated by script anyway, but purge the stale file).
- `public/robots.txt` → `Sitemap:` line.
- Grep-verify zero remaining `site-host-finder.vercel.app` occurrences after edits.

Add 301 redirects in `vercel.json` from `https://site-host-finder.vercel.app/*` → `https://sitehostfinder.online/$1`. Because Vercel redirects are host-scoped through the project's domain settings and both hosts point to the same deployment, add a `has: [{ type: "host", value: "site-host-finder.vercel.app" }]` rule matching every path and 301'ing to the new host — no path rewrites needed (paths already match 1:1).

## 2. Fix "tool falls asleep" / cold-start reliability

Root cause: Supabase Edge Functions cold-start after idle; the UI shows a stuck spinner or blank on timeout.

Changes:
- **Client fetch wrapper** (`src/lib/invokeWithRetry.ts`): wraps `supabase.functions.invoke` with 15s timeout, 2 retries (exponential backoff 500ms/1500ms), and typed error result. Used by all tools and Results page.
- **Loading states**: replace text preloaders with existing `ResultsSkeleton` on every tool card; show inline "Warming up… retrying" message after first failed attempt.
- **Fallback UI**: on final failure show a friendly card with retry button + link to related tool — never a blank screen.
- **Health endpoint**: add lightweight `supabase/functions/health/index.ts` returning `{ok:true, ts}` with `verify_jwt=false`.
- **Keep-alive**: `src/lib/keepAlive.ts` pings `/health` every 4 minutes while the tab is visible (visibilitychange-gated so it stops when hidden — no wasted invocations). Fires once on app mount from `src/main.tsx`.
- **Client timeout guard** on `IsItUpTool`, `PortCheckerTool`, `WhatIsMyIPTool`, and the Results loader.

## 7. Sitemap lastmod policy compliance

Current `scripts/generate-sitemap.ts` writes `new Date().toISOString()` for every URL — that's the forbidden "current date fallback". Fix: **omit `<lastmod>` entirely** (no authoritative per-page timestamp source in this project). Keeps sitemap honest and stops false freshness signals.
