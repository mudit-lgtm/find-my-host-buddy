Why does Cloudflare show as the host?

If a website uses Cloudflare's CDN, DNS resolves to Cloudflare's edge servers. The actual origin host is hidden behind the Cloudflare network.

What is a hosting provider vs a domain registrar?

A domain registrar is where you purchase and manage your domain name (e.g., Namecheap, GoDaddy). A hosting provider stores your website files on a server and makes them accessible online. They can be the same company or different ones.

What is WHOIS and how does WHOIS lookup work?

WHOIS is a public database of domain registration records maintained by ICANN. Our WHOIS lookup queries this database to show domain registration date, registrar, expiry date, and domain age.

How do I find the IP address of a website?

Use our IP address lookup — enter the domain to see IPv4 (A record) and IPv6 (AAAA record) addresses with geolocation and hosting provider identification.

What are nameservers and MX records?

Nameservers are DNS servers that store all DNS records for a domain — incorrect settings can take a website offline. MX records specify which mail server handles email for a domain. Our DNS lookup tool shows all record types.

How do I check if a website uses Cloudflare?

Enter the domain into our hosting checker. If nameservers end in .ns.cloudflare.com and the IP belongs to Cloudflare's range, the site uses Cloudflare CDN.

Hosting Guide — How to Find & Choose a Web Host

What is Web Hosting?

Web hosting is a service that stores your website files on a server connected to the internet. When someone types your domain into their browser, DNS records point to your hosting provider's server, which delivers your website. Use our hosting checker to see which provider any site uses.

DNS Records Explained

DNS records map domain names to IP addresses and services. Key record types: A records (IPv4 address), AAAA records (IPv6), MX records (email servers), NS records (nameservers), CNAME (domain aliases), TXT records (verification and SPF). Our DNS lookup tool shows all record types instantly.
